Office Studio 1.0.3 · Windows 10/11 x64

Sheet Studio 0.7.28, Slide Studio 1.6.15, Word Studio 1.4.9를 선택해 한 번에 설치합니다. 최신 main에서 다시 빌드했습니다.

세 앱의 지원 파일 등록을 개선해 기존 기본 앱을 유지하면서 연결 프로그램 후보로 사용할 수 있습니다. 설치·제거 시 다른 프로그램의 등록 정보도 보존합니다. Word의 HWP 페이지 경계·줄 간격과 중첩 표 격자·정렬 개선을 포함합니다.

Windows는 자동 확인·다운로드 후 문서를 저장하고 종료하고 업데이트로 설치합니다. 도움말에서 자동 확인·다운로드를 끌 수 있습니다. 코드 서명이 없어 SmartScreen 경고가 표시될 수 있으므로 공식 파일을 확인한 뒤 추가 정보 → 실행을 선택하세요.
