Office Studio 1.0.4 · Windows 10/11 x64

Sheet Studio 0.7.29, Slide Studio 1.6.16, Word Studio 1.4.10을 선택해 한 번에 설치합니다. 최신 main의 앱 코드를 다시 빌드했습니다.

Sheet의 수식·표·차트 및 Excel 호환성 개선, Slide의 PPTX 원본 요소 보존·손실 안내·편집 가능한 차트·인쇄 화면 정리, Word의 HWP·DOCX 페이지 나눔·표 배치·문자별 글꼴·탭과 반복 저장 시 표 너비 보존 개선을 포함합니다. 복잡한 문서는 저장 결과를 원본과 비교해 확인하세요.

Windows는 자동 확인·다운로드 후 문서를 저장하고 종료하고 업데이트로 설치합니다. 도움말에서 자동 확인·다운로드를 끌 수 있습니다. 코드 서명이 없어 SmartScreen 경고가 표시될 수 있으므로 공식 파일을 확인한 뒤 추가 정보 → 실행을 선택하세요.

Windows 통합 설치·재설치·제거, 문서 및 사용자 데이터 보존, 이전 앱에서 실제 업데이트 도우미로 설치·실행·정상 종료를 확인했습니다. [검증 기록](https://github.com/beaur8-prog/office-studio/actions/runs/41051634834)

Mac Apple Silicon 배포는 별도 mac-v1.0.4 릴리스를 사용합니다. 자세한 검사 범위는 RELEASE-VALIDATION.json을 확인하세요.
