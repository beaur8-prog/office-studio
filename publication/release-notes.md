Office Studio 1.0.5 Windows 배포

자동 업데이트 안내: 기존 버전에서 ‘종료하고 업데이트’를 눌러도 앱만 닫히던 문제를 수정했습니다. 기존 사용자는 문서를 저장하고 세 앱을 종료한 뒤 이 최신 통합 설치 파일을 한 번 직접 실행해 주세요. 이후에는 앱별 업데이트 화면에서 새 버전을 확인·다운로드하고 설치를 진행할 수 있습니다. 설치 화면이 나타나면 안내에 따라 완료하세요.

- Sheet Studio 0.7.36
- Slide Studio 1.6.21
- Word Studio 1.4.11

Windows 10/11 x64용이며 필요한 앱을 선택해 설치할 수 있습니다. 자동 확인·다운로드는 각 앱에서 끌 수 있고 새 버전 설치를 나중으로 미룰 수 있습니다.

설치 파일은 배포용 코드 서명을 받지 않아 Windows 보안 경고가 나타날 수 있습니다. 공식 다운로드의 출처와 체크섬을 확인하세요.

Mac은 별도 mac-v1.0.5 릴리스로 제공합니다. Mac 업데이트는 ZIP 다운로드 후 직접 교체 방식입니다.
