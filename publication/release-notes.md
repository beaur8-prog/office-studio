Office Studio 1.0.6 · Windows x64

Word Studio 1.4.12의 Windows 설치 언어 자동 선택 개선을 포함합니다. Sheet Studio 0.7.36과 Slide Studio 1.6.21은 이전 배포 파일을 유지합니다.

Word Studio 1.4.11 사용자는 앱에서 업데이트 확인 → 다운로드 → 종료하고 업데이트를 선택해 1.4.12로 업데이트할 수 있습니다. 문서를 먼저 저장하고 설치 화면의 안내를 따라 진행하세요.

업데이트 기능이 없거나 버튼을 누르면 앱만 닫히는 이전 버전은 통합 설치 파일을 한 번 직접 설치해 주세요.

이번 배포는 Windows 전용입니다. Mac 통합본은 mac-v1.0.5, Mac Word는 1.4.11을 유지합니다.
