Windows 설치형 앱에 업데이트 확인과 자동 다운로드를 추가했습니다.

- 실행 후 새 정식 버전을 자동 확인하고 백그라운드에서 다운로드합니다.
- 도움말 → 업데이트 확인…에서 수동으로 확인할 수 있습니다.
- 종료하고 업데이트를 선택하면 문서 저장·종료 절차를 거친 후 설치하고 다시 실행합니다. 문서 닫기를 취소하면 업데이트도 취소합니다.
- 이 릴리즈는 Windows x64용입니다. Mac·Linux는 이전 개별 배포를 이용해 주세요.
- 코드 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다. 배포 출처와 SHA-256을 확인해 주세요.
