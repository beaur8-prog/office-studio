Slide Studio 1.6.11 · Mac Apple Silicon 배포

- Apple Silicon(M1 이상), macOS 12 이상.
- Mac 릴리스만 확인해 새 버전을 자동 다운로드하고, 문서 저장·종료 후 ZIP을 직접 교체하도록 안내합니다.
- 도움말에서 자동 확인·다운로드를 끌 수 있습니다.
- 앱은 ad-hoc 서명 상태이며 Apple Developer ID 서명·공증은 없습니다.
- 최근 표 행 높이와 테두리 표시 수정을 포함합니다.

이 릴리스는 Mac 전용이며 GitHub의 Windows latest 릴리스를 변경하지 않습니다.
