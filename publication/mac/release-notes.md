Office Studio 1.0.0 Mac 배포입니다. Apple Silicon(M1 이상) · macOS 12 이상에서 사용합니다.

- Sheet Studio 0.7.23
- Slide Studio 1.6.11
- Word Studio 1.4.5

한 PKG에서 설치할 앱을 선택할 수 있습니다. Developer ID 서명·공증은 없으며 시스템 설정의 앱별 열기 허용이 필요할 수 있습니다. 앱 업데이트는 Mac 릴리스를 자동 확인·다운로드한 뒤 ZIP을 직접 교체하는 방식입니다.

최종 PKG의 앱 버전·서명 무결성·편집 코드 일치와 세 앱의 실제 시작·종료·업데이트 설정을 검증했습니다. 관리자 권한을 사용한 시스템 설치 시험은 수행하지 않았습니다. 자세한 범위는 BUILD-mac-arm64.json과 MAC-VERIFICATION.json을 확인하세요.

Windows 배포는 기존 v1.0.0 릴리스를 사용합니다.
