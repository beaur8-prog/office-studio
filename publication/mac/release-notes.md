Office Studio 1.0.4 Mac 배포입니다. Apple Silicon(M1 이상) · macOS 12 이상에서 사용합니다.

- Sheet Studio 0.7.29
- Slide Studio 1.6.16
- Word Studio 1.4.10

Sheet의 수식·표·차트 및 Excel 호환성, Slide의 PPTX 원본 요소 보존·손실 안내·차트 편집·PDF 출력, Word의 HWP·DOCX 페이지 나눔·표 배치·문자별 글꼴·탭과 반복 저장 시 표 너비 보존을 개선했습니다. 복잡한 문서는 저장 결과를 원본과 비교해 확인하세요.

한 PKG에서 설치할 앱을 선택할 수 있습니다. Developer ID 서명·공증은 없으며 시스템 설정의 앱별 열기 허용이 필요할 수 있습니다. 앱 업데이트는 Mac 릴리스를 자동 확인·다운로드한 뒤 ZIP을 직접 교체하는 방식입니다.

최종 PKG의 앱 버전·서명 무결성·편집 코드 일치와 세 앱의 실제 시작·종료·업데이트 설정을 검증했습니다. 패키징된 Word의 DOCX·HWP/HWPX 편집·저장과 Slide의 PPTX 보존·차트·PDF·GIF/MP4/WebM도 검사했습니다. 관리자 권한을 사용한 시스템 설치 시험은 수행하지 않았습니다. 자세한 범위는 BUILD-mac-arm64.json, MAC-VERIFICATION.json, RELEASE-VALIDATION.json을 확인하세요.

Windows 배포는 별도 v1.0.4 릴리스를 사용합니다.
